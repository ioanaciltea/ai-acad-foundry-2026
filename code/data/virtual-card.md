# Libra Bank Virtual Card

The virtual card is a card without physical support, generated instantly from the Libra Assist app, used exclusively for online payments and digital subscriptions.

Issuing a virtual card is free and unlimited in number — a customer can have multiple active virtual cards simultaneously, each linked to an existing current account.

The virtual card cannot be used for cash withdrawals at ATMs and cannot be used for physical POS payments. The daily spending limit for a virtual card is 5,000 RON, the same regardless of the associated account type.

A virtual card can be deactivated instantly from the app with zero fees, and a new one can be generated immediately in its place.
