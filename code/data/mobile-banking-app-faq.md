# Mobile Banking Application Guide & FAQ

The Libra Mobile Banking App allows retail customers to manage accounts, make transfers, and configure security settings directly from iOS or Android smartphones.

## 1. Authentication & Security Features

* **Biometric Sign-In**: Face ID and Touch ID / Fingerprint login supported on compatible iOS (iOS 15+) and Android (Android 10+) devices.
* **Transaction Step-Up Verification**: Transfers exceeding 1,000 RON or transfers to newly added beneficiaries require biometric confirmation or a 6-digit Security PIN.
* **Device Binding**: Each customer account can be actively paired with up to three (3) mobile devices simultaneously.

## 2. Common Troubleshooting Steps

### Forgot Mobile PIN
1. Open the Libra Mobile App login screen.
2. Tap "Forgot PIN?".
3. Verify identity using your registered phone number, national ID (CNP), and one-time SMS passcode.
4. Set and confirm your new 6-digit PIN.

### Device Pairing Reset
If your phone is lost or replaced:
1. Log into Desktop Internet Banking using your web credentials.
2. Go to `Settings` -> `Connected Devices`.
3. Select the lost device and click `Revoke Access`.
4. Install the mobile app on the new phone and follow the activation workflow.
